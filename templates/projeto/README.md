# Templates para iniciar projetos

Escolha as seções conforme o escopo e a equipe. Remova instruções de preenchimento da versão final e use os termos do projeto.

- [README de projeto](readme-projeto.md) para objetivo, uso e navegação.
- [Especificação de projeto](especificacao.md) para visão, requisitos, casos de uso, arquitetura, interface, planejamento, testes e operação. Cada seção pode virar um arquivo quando precisar de revisão própria.
- [ADR](adr.md) para uma decisão arquitetural com impacto.
- [Issue de entrega](../../.github/ISSUE_TEMPLATE/entrega.md) para ligar requisitos e casos de uso a uma mudança verificável.
- [Exemplo aplicado](../../exemplos/reservas-de-recursos/README.md) para ver os documentos, diagramas e issues com conteúdo fictício.
- [Ficha de diagrama](diagrama.md) para público, fronteira, fonte e revisão.
- [Plano de testes](plano-testes.md) para cenário, massa, evidência e resultados.
- [Defeito](../../.github/ISSUE_TEMPLATE/defeito.md) e [investigação](../../.github/ISSUE_TEMPLATE/investigacao.md) para entregas com formatos próprios.
