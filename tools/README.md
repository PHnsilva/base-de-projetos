# Ferramentas do acervo

| Ferramenta | Entrada | Saída |
| --- | --- | --- |
| [Verificar links locais](documentacao/validar.mjs) | Arquivos Markdown do repositório | Lista de destinos ausentes e código de saída para automação |
| [Configurar o Project didático](github-project/README.md) | Data inicial e plano revisado | Prévia local ou aplicação autenticada de campos, cartões, tipos, marcos e bloqueios |
| [Exportar documentação](documentacao/exportar.mjs) | Diretório de documentos Markdown | ZIP com Markdown, fontes Mermaid e PDFs opcionais |

O [guia de execução](documentacao/README.md) descreve requisitos, exemplos, limites e verificação. Antes de adaptar uma ferramenta, confira o formato de entrada, acesso aos arquivos, dependências e o que ela grava. Os exemplos usam dados sintéticos.
